千川巡航 · Windows x64

1. 将 ZIP 全部解压到一个固定文件夹。双击「千川巡航.exe」。
2. 点「复制机器码」，发给签发人。收到授权码后粘贴并点「激活或续期」。
3. 点「打开工作台」。新安装请到「官方 API 接入」配置你自己的应用并授权，再添加账户和保存规则。
4. 如果需要网页追投，请单独安装 Ego 浏览器，完成对应账户登录和执行器配置。只有希望使用 Chrome 扩展采集时，才点「导出 Chrome 扩展」，再在 Chrome 扩展页加载该目录。

关闭启动器窗口后后台可继续运行。需要退出后台时，点「停止后台」。也可以主动勾选随 Windows 登录启动。

授权绑定当前 Windows 安装，到期后后台停止。续期时可直接粘贴新码。如果重装系统导致机器码变化，请以新的机器码申请授权。

运行数据位于当前用户的 %LOCALAPPDATA%\QianchuanCruise。安装包本身无需写入。千川 API 凭据和浏览器登录状态按各自工具保存在当前电脑。

如提示 8877 端口已被占用，请先核对是否运行了其他巡航实例。Chrome 扩展默认连接端口 8877。
