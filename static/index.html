浏览器只读采集
尚未连接浏览器采集器。
连接和采集范围以上方实时状态为准。已连接的扩展继续使用；以下为首次安装步骤。
  1. 打开 Chrome 扩展管理页，开启开发者模式，点击“加载已解压的扩展程序”。
  2. 选择本程序目录下的 extension 文件夹。
  3. 保留接入配置中的分组和指定页面。扩展只读取可见汇总，每分钟一次。
  4. 打开扩展图标，粘贴下方配对码，点击“授权并开始只读采集”，在Chrome确认千川站点与本机8877访问。首次安装默认暂停。


配对码只在本机控制台与扩展之间复制，不需要发给对话。扩展不申请全局tabs权限，站点授权由你点击时确认；Chrome授予域级脚本访问，当前源码再按本机明确配置的账户ID、分组和允许页面路径限制读取；只有新版采集器通信就绪后才允许修改范围。采集器不点击、不刷新页面，不读取Cookie或平台登录存储。页面不更新或布局变化时，数据会过期或缺失。


导入官方账户报表结果
可将已取得的账户聚合报表响应与实际查询参数放入模板，在本机校验后导入。当前支持“获取千川投放账户维度数据”；不会自动运行可视化调试，也不需要提供开发者凭据。
只放查询参数和业务响应，移除请求头、Cookie、令牌及授权响应。字段、日期或接口不符会拒绝；未知数据更新时间留为null。模板默认值需按真实查询修改，空模板不能导入。


全域 / 乘方报表明细核对
核对已取得的“可用维度和指标”配置、实际查询参数及分页业务响应。支持计划、素材、商品等数据主题，按配置展示字段名称、原生单元格和单位。
未知数据更新时间保持null。原生嵌套值不会自动换算为ROI、金额或订单；核对不保存观察快照，也不发送给AI。只提供无凭据的业务结果，空模板不能当作已采集数据。


控成本素材追投创建预览
仅核对当前完整评估中的直播全域单视频追投及明确成交出价、达人定向。账户ROI目标留空时不能准备；登记不会创建任务或注册截止。
素材映射和定向为提供者声明，尚未认证原生来源。2至4小时作为本地截止要求，真实截止调度与追投创建仍未接通。
创建后新任务核对
将准确的新任务ID、原创建意图和任务列表响应对应核对。文件只显示配置及报告状态，不解除母计划占用。
原生读取与核对客户端默认关闭，没有网页读取或解锁入口；无任务ID的未知请求不按名称猜测恢复。当前模板仅用于直播全域一键起量。


素材配置与状态核对
比较已取得的计划详情创意配置和素材列表业务响应。配置是否包含原生标识、列表报告的投放/审核状态分别展示；列表未命中不能证明素材已删除。
上传无凭据的业务结果，不调用平台、不保存快照或改变流程占用。文件内数字ID会在服务端无损解析；原生读取适配器默认关闭，没有网页启用入口。


程序化素材替换草稿
使用完整用途清单和已审核候选池，绑定当前母计划及合格弱创意。每计划只准备一个小步替换，先添加、核对、等待冷却，再重新评估退旧。
登记需与当前快照及独立时刻匹配。容量、复用或可删除来源不明时保持阻断。预览本身不保存；合格草稿可另存为本地待接通流程，不提交素材操作或授予权限。合成例子在临时库中回放。


素材流程进度
保存到本机的流程会占用对应母计划和账户重复数量，避免叠加调整。真实素材提交尚未接通，已保存流程保持等待；添加前可以取消并释放本地预留。


导入结构化报告
观察快照使用含 snapshots 的 JSON；人工变更报告或模拟记录使用单独含 events 的文件。格式见 docs 数据协议。导入会校验对象、时间与前后值，不执行调控，也不授予保障或历史核验资格。


旧程序日志与数据库
每60秒只读检查原目录中的日志和 SQLite 数据，不调用旧程序的刷新、启停或账户调控接口。


官方 API 的后续接入
浏览器登录与开放平台 API 授权相互独立。拿到账号报表权限后，可由只读适配器按数据协议导入。运行中的服务没有广告提交入口；源码中的预算提交适配器保持断开，未读取凭据或提交调控。
程序运行依赖本机服务；浏览器采集依赖 Chrome 保持开启。没有连接或数据过期时自动停止策略资格判断。
