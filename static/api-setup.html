创建应用所需资料

应用名称
千川巡航
用途说明
企业内部多账户直播与商品投放管理，支持全域和乘方入口。读取账户、计划、素材及效果数据，按各账户规则生成调控单，经人工逐条确认后执行并核验结果。
业务范围
巨量千川 PC 版；按后台实际主体选择自研投放应用。
本机授权回调

回调地址需先在开发者后台通过校验并保存。若后台不接受本机 HTTP 回调，需配置实际可用的 HTTPS 回调方案，再完成接入；当前程序不向公网开放。

已提交申请的能力：PC 全域投放管理（21010000）、千川乘方投放管理（200000064）、获取全域投放数据（22100600）、全域计划调控工具（200000037）、数据报表（22100000）。实际可授权权限以审核后的应用后台为准。

保存本机应用配置

Secret 和 Token 使用当前 Windows 用户加密保存，不回显、不写入日志、不进入源码交付包。更换应用或权限配置将清除本机旧授权。

授权与连接检查

账户管理员在官方页面核对账户和权限后完成授权。多个登录账号可分别建立连接。

读取已登记账户

按本户所选“全域／乘方”入口读取今天的消耗、整体支付 ROI 和成交数据。选择两者时分别展示，接口缺失字段保持空值。已授权并启用监测的账户约5分钟自动更新一次。

设置每户的投放入口

当前接入阶段：应用配置、OAuth、Token 刷新、授权账户、账户汇总和计划报表。直播素材报表、成交/ROI/放量追投、任务暂停及增预算/延时、主计划预算/ROI/暂停、起量和下播控量排程已接入逐单确认。首批示例分组A成交追投已真实创建并回读；其余写入路径已通过模拟回归，需分别实投验收。自动条件缺值会明确说明，不以其他指标代替。现有浏览器调控单不会转入 API 执行。
